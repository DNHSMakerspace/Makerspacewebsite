# DNHS Makerspace

A deployable static React app for the DNHS Makerspace club.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The build output is generated in the `dist/` folder and is ready to deploy to static hosting platforms like Netlify, Vercel, GitHub Pages, or Cloudflare Pages.

## Notes

- The app is designed for static hosting.
- The login and upload features are front-end only for now.
